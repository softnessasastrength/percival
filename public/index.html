This is the public face of the Percival Core service: a deny-by-default tool registry, a redacted audit log, and a deterministic, dry-run-first executor, built on the Python standard library alone.

Status: core service prepared for deployment; production deployment awaits its owner's approval. Nothing on this surface sends, books, spends, or acts in the world.

Service endpoints

  • GET /api/health — service name, version, and the foundation modules present in this runtime, reported as facts.
  • /api/demo — a registry and executor demonstration that runs in dry-run mode only: authorization is checked, the outcome is audited for the life of the request, and the tool is never invoked. GET describes it; POST with {"message": "…"} runs it.
